defines the observed PV-affinity message. The corrected assertion accepts
these two specific messages only with `FailedScheduling` and the exact
synthetic Pod UID, and records the actual reason/message/workers.
Regression cases reject a different UID/reason, Pod selector conflicts,
taints, memory exhaustion and generic volume failures.

Pod API watch endpoint with the captured resourceVersion and explicit
900-second API / 910-second client bounds. An ended watcher still fails
closed. Operator SSH replaces its wrapper process via exec so terminating
the watch also terminates the SSH client.

The correction changes the checker/source digest; rendered installation
resources, site inputs, approved mutation scope and cleanup guards are
unchanged. A fresh revision/digest and full checks are required before retry.
No additional installation apply is needed.
